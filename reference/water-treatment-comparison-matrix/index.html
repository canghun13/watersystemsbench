How to use the matrix

Start with the tested problem and intended use, remove technologies without an applicable objective, check upstream protection and downstream monitoring, then compare service flow, pressure loss, waste and maintenance. Use the longer comparison guide for scenarios and ordering decisions.

Reference boundary. Do not convert an indicative value into a universal design, health or legal requirement. Check the cited source, laboratory context, certified claim and applicable jurisdiction.
