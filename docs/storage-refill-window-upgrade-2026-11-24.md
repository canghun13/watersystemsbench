Repeat use: compare cycle length, window, measured minimum flow and existing capacity. Inputs: daily demand D (L/day or US gal/day), cycle days C, one contiguous available refill window H (hours per cycle), source flow Q (L/min or US GPM), reserve percent R, usable fraction F, existing nominal volume E. Internal L/h and L. Daily demand is constant across both phases. No peak-rate schedule, multiple windows, water age, initial-state simulation, pressure, treatment or fire sizing.

T = 24C; d = D/24; available supply S = 60QH; cycle demand V = DC. If S < V: report continuing shortfall V−S and minimum source flow V/(60H) when H>0, no finite sustainable nominal size (null, not zero), and no fabricated refill time. Increasing tank size cannot cure this repeating deficit. H=0 or Q=0 with positive demand follows this branch. No tolerance silently accepts a true deficit.

Otherwise the no-supply gap G=T−H requires working swing W=dG. Net refill rate is 60Q−d; recovery time W/(60Q−d), with continuous-supply W=0 giving zero recovery. Required usable W(1+R/100), nominal usable/F, additional max(0, nominal−E). Report cycle supply/demand/margin, gap, swing, simultaneous-demand net refill, recovery and window slack. Reserve is an entered allowance on working swing, not a guaranteed extra outage duration. Existing tank subtracts physical nominal volume only, same usable fraction assumption. Excess inflow requires proper level control, not uncontrolled overflow. Exact balance has no source margin. Continuous balanced supply can have zero *balancing* storage, explicitly not approval of zero installed storage.

Validation: finite daily demand >0≤1e8 L/day; cycle >0≤365 days; 0≤H≤T; 0≤Q≤1e5 L/min; reserve 0–200%; 0<F≤1; E 0–1e8 L. UI unit limits apply after SI conversion in new mode.
